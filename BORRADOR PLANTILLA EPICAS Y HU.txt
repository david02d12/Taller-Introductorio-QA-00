EP-001 Gestion de Autenticacion y Perfil de Usuario
Nombre
Iniciar Sesion
Prioridad
Alta
Sprint
Sprint 1
Story Points
5 SP
Historia
Como: Cliente/Tecnico/Administrador
Quiero: Iniciar sesion en la plataforma
Para: Acceder a mis funciones segun mi rol
Descripción Funcional
El sistema debe permitir a los usuarios registrados iniciar sesion mediante email y contrasena, validando credenciales y generando un token JWT.
Reglas de Negocio
RN-001: Email y contrasena obligatorios.
RN-002: Contrasena debe estar encriptada (bcrypt).
RN-003: Token JWT expira en 24h.
Datos Requeridos
Campo    Obligatorio    Validacion
Email    Si    Formato email valido
Contrasena    Si    Minimo 8 caracteres
Criterios BDD
CA-001 Login exitoso
Dado que el usuario ingresa credenciales validas
Cuando presiona iniciar sesion
Entonces el sistema genera token JWT y redirige al dashboard.
CA-002 Credenciales incorrectas
Dado que ingresa credenciales invalidas
Cuando intenta iniciar sesion
Entonces el sistema muestra mensaje de error.
Dependencias
RF001.
Mockups
Pendiente.
Definition of Done
• Backend valida credenciales.
• Token JWT generado.
• Middleware protege rutas.
Casos de Prueba
CP-001: Login con credenciales validas.
CP-002: Login con contrasena incorrecta.
CP-003: Login con email inexistente.
Riesgos
• Fuerza bruta en login.
• Token expuesto.
Trazabilidad
RF001, CU001, EP-001
